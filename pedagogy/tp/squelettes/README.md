# Répertoire des Squelettes de Code pour le TP

Ce dossier contient les fichiers "à trous" fournis aux camarades de classe pour la réalisation des exercices du TP dirigé :

- `models_skeleton.py` : Squelette pour l'Exercice 1 (Définition du modèle `Expense` et configuration Admin).
- `queries_skeleton.py` : Squelette pour l'Exercice 2 (Optimisation des requêtes avec `select_related` et agrégations `Sum`).
- `transactions_skeleton.py` : Squelette pour l'Exercice 3 (Sécurisation transactionnelle avec `transaction.atomic` et `select_for_update`).

> Les fichiers complets seront activés lors de la séance en salle de TP.
